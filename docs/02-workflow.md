# 02 — 核心工作流

## 概述

产品围绕三个一级页面运作：

```txt
Template
Collage
Settings
```

其中 Template 与 Collage 是独立的生产工作流，Settings 负责默认行为与系统设置。

---

## 2.1 Template 工作流

```txt
导入图片 → 选择模板 → 调整 Template Props → 预览 → 导出 / 批量导出
```

### 关键特征

- 以单图渲染为核心
- 模板通过 `propsSchema` 自动生成编辑表单
- 每张图片各持一份模板配置（模板、参数、背景、导出档位），可一键应用到其余图片
- 导出结果直接来自 `<TemplateRuntime />`
- 素材只在当前 Template 页面内可见

---

## 2.2 Collage 工作流

```txt
打开文件夹 → 文件夹树 / 图片预览栏选图 → 拖入画布 → 选择布局模式 → 调整布局与选中项属性 → 预览 → 导出
```

### 关键特征

- 以多图组合为核心
- 支持 `Grid Layout` 与 `Free Layout`
- 素材获取采用文件夹直览：左侧文件夹树选择目录，右侧图片预览栏以缩略图网格展示该目录的图片
- 打开文件夹只枚举路径，缩略图按需生成，图片拖入画布时才复制进缓存
- 素材区只服务于当前拼图会话：记住上次打开的文件夹，重开自动恢复
- 导出结果直接来自 `<CollageCanvas />`

---

## 2.3 Settings 工作流

```txt
进入设置页 → 选择配置分类 → 修改默认行为 → 自动保存
```

### 配置分类

- General
- Template
- Collage
- Export
- Cache
- About

---

## 2.4 素材获取原则

Template 遵循导入原则：

- 支持拖拽导入
- 支持系统文件选择导入
- 素材导入后立即进入可预览状态
- 额外支持粘贴导入、文件夹导入、多选与排序
- 不依赖项目保存才能继续工作

Collage 遵循文件夹直览原则：

- 通过文件夹树或目录选择器打开本地文件夹
- 打开文件夹只枚举图片路径，不复制原文件
- 缩略图按需生成，图片拖入画布时才复制进缓存
- 「移除」只把图片从当前列表隐藏，不删除本地文件
- 记住上次打开的文件夹，重开自动恢复；路径失效时提示重新选择
- 支持拖入画布槽位（放入或替换）
- 不依赖项目保存才能继续工作

---

## 2.5 导出原则

- 导出来自当前 Workspace 的真实渲染结果
- 导出不依赖隐藏渲染路径或独立编辑器实现
- Template 与 Collage 共用导出基础设施，但不共享页面状态
- 批量导出始终展示进度与可取消状态
