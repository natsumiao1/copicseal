# 09 — 拼图系统

## 概述

Collage 页面负责多图拼接与导出，是与 Template 平行的独立功能域。

路径：

```txt
/collage
```

核心原则：

```txt
Collage 与 Template 完全独立
```

禁止：

- 共享编辑器
- 共享布局逻辑
- 共享状态

仅共享：

- Export Pipeline
- Asset Infrastructure

---

## 页面布局

```txt
┌────────┬──────────┬─────────────┬──────────────┬──────────────┐
│        │ 文件夹树  │ 图片预览栏  │              │              │
│ Nav    │          │             │ Collage      │ Properties   │
│        │          │             │ Preview      │              │
│        │          │             │              │              │
└────────┴──────────┴─────────────┴──────────────┴──────────────┘
```

- 文件夹树与图片预览栏统称素材区，只属于当前拼图会话
- Collage 不渲染 Template 式的下方 Assets 条

## 9.1 Workspace

Collage 的 Workspace 渲染：

```tsx
<CollageCanvas />
```

支持：

- Grid Layout
- Free Layout

导出结果直接来自当前画布区域。

## 9.2 顶部工具栏

提供布局切换入口：

- `2 Grid`
- `3 Grid`
- `4 Grid`
- `6 Grid`
- `Auto Layout`
- `Free Layout`
- `自适应`：进入自适应布局（见 9.6）；切换布局模式会清空自适应树，进入时画布为空
- `清空画布`：仅自适应模式显示，一键移除画布上的全部照片（只清画布，不删除任何文件；
  画布为空时按钮禁用）
- `布局库`：弹窗按图片数量分组展示 `layouts.ts` 中的全部布局预设，每项带槽位缩略图
  （12×12 槽位表按百分比等比绘制，与画布排布一致）；选择后画布切换到该布局。
  当前布局不属于上述快捷预设时，该按钮保持按下态。

## 9.3 Properties

Properties 使用 `Accordion` 组织，至少包含以下区块。

### Layout

- 画布比例（自适应模式下不可选，改为「跟随内容」说明）
- 间距
- 边距
- 背景色
- 圆角
- 阴影

### Selection

选中图片后显示（自适应模式下整个区块隐藏，该模式无位移/缩放/旋转概念）：

- 缩放
- 位置
- 旋转
- 圆角

### Export

与 Template 使用相同的导出参数结构：

- PNG
- JPG
- WEBP
- 质量
- 倍率
- 导出

## 9.4 素材区（文件夹直览）

Collage 素材区只属于当前拼图页面，由两个左侧栏组成。

### 文件夹树

- 根节点：最近使用的文件夹、用户主目录、外接磁盘
- 点击按需展开子目录，不做递归扫描
- 选中目录后右侧图片预览栏加载该目录

### 图片预览栏

- 缩略图网格展示目录内图片，按文件名排序
- 点击选中当前图片，选中态与画布、属性面板联动
- hover 显示「移除」：仅从列表隐藏，不删除本地文件
- 未打开文件夹时显示「打开文件夹」入口
- 提供手动刷新，重新枚举目录内容

### 加载策略

- 打开文件夹只枚举图片路径，不复制原文件
- 缩略图由后台任务直接以原文件为源按需生成
- 图片拖入画布或加入会话时才执行缓存导入
- 大目录需虚拟滚动，避免一次性渲染全部条目

### 支持

- 打开文件夹
- 浏览文件夹树
- 拖入拼图（拖到槽位即放入或替换）
- 移除条目（不删除本地文件）
- 点击切换当前图片

### 会话行为

- 记住上次打开的文件夹（`folderPath`），重开自动恢复
- 路径失效时提示重新选择，不伪造目录内容
- 「移除」记录为会话内的隐藏路径集合

## 9.6 布局能力

### Grid Layout

- 适合规则拼图
- 由布局预设驱动
- 优先支持固定格数与自动布局

### Free Layout

- 适合自由摆放
- 支持位置与缩放调整
- 单图属性由 Selection 面板控制

### Adaptive Layout（自适应）

- 按拖放方位动态生成布局：新照片拖到目标照片的哪一侧，目标矩形就一分为二
  （左右 → 两列，上下 → 两行；递归进行，例如下半区再左右分即「上一下二」）
- 数据结构为二叉分割树（`adaptiveTree`，leaf = 一张照片，split = 按 `h`/`v` 二分），
  随 undo/redo 与持久化走；移除照片时父节点自动塌缩为兄弟
- **所有照片保持原始宽高比**：左右分两子树等高、宽度按比例分配，上下分两子树等宽、
  高度按 `1/比例` 分配；每个格子的比例 == 照片比例，无缝填满、零裁切零变形
- 画布整体比例**跟随内容**（根节点比例）；**间距与边距相互独立**：间距只作用于照片
  之间（贴画布外沿的边不参与内缩），边距只控制外圈留白、可调至 0
- 交互：贴边（30% 带）高亮插入方位，中央区域高亮替换，空画布拖入即第一张；
  hover 照片浮现「移除」（只出画布，不删除文件）
- **画布外沿整体插入**：拖到照片贴合画布外沿的边，或直接拖到照片与画布边距之间的
  外框区域 → 沿该侧在根节点一分为二，新照片独占一整行/一整列（如在底部追加
  第三行）；画布内部的边缘拖放仍按单张照片细分
- 导入/点击预览栏**不自动放置**，一律手动拖入；同图在画布中只保留一份
- 照片原始宽高由导入元数据提供（`CachedImageMeta.width/height`，含 HEIC ispe 解析），
  解析失败按 3:2 兜底

## 9.8 2026-10-04 文件夹直览约束补充

- 素材区改为左侧双栏：`文件夹树 + 图片预览栏`，经由 `shared/layouts/business-workbench` 的可选左侧栏插槽接入
- `Assets` 插槽对 Collage 变为可选，Template 布局保持不变
- 直览条目的 `id` 取自文件路径，保证跨会话稳定，使持久化的画布槽位能继续指向同一文件
- 直览与懒导入为桌面端能力；产品已放弃 Web 端，不提供浏览器降级路径

## 9.9 编辑历史（撤销/重做）

- 画布状态（布局与画布属性、间距/边距、槽位调整、自适应树改动）统一进撤销历史，
  最多 60 步，不跨会话持久化
- 快捷键：`Cmd/Ctrl+Z` 撤销，`Cmd/Ctrl+Shift+Z`（Windows `Ctrl+Y`）重做；
  随拼图页挂载/卸载，其他页面不拦截
- 焦点在输入控件（输入框/文本域/`contenteditable`）时不拦截，交还原生文本撤销
