## 3. 旧版对齐清单

> 与旧版桌面应用的差异盘点，供产品负责人逐条决定「改 / 不改」。
> 旧版代码在仓库 `dev` 分支（tip `5d18df1`），用 `git show dev:<path>` 查看。
> 类型：`缺口` 旧有新无 ／ `默认值` 行为相同默认不同 ／ `缺陷` 新版自身问题。
> 成本：`极小` 单点 ／ `小` 单文件到单面板 ／ `中` 跨 2–3 模块或需新增持久化 ／ `大` 需新数据层或新页面级能力。

### A. 功能缺口（旧有、新无）

- [ ] **A1 输出尺寸快捷项**｜缺口｜成本 小 —— 旧版「+」下拉固定 10 项常用尺寸（1080P / 2K / 4K / 方图 / 朋友圈 / 小红书等），新版预设对话框只能手填「调整大小至」的像素值，无常用尺寸快捷项
- [ ] **A2 「原始图片」档位**｜缺口｜成本 极小 —— 已被预设的「缩放图像 100%」（照片原始像素 1:1）覆盖；残余部分：Rust 已读 `PixelXDimension` 但无人消费（如按 EXIF 宽高自动回填数值）
- [x] **A3 宽高互换**｜成本 极小 —— 结构性取消：新模型没有两轴手填，长边 / 短边 / 宽度 / 高度轴选择器已覆盖切换语义
- [ ] **A4 预设排序**｜缺口｜成本 小 —— 旧版设置页输出表格支持上移 / 下移；新版预设列表按创建顺序排列，仅支持增删改与复制
- [x] **A5 「存为默认」档位与导出目录**｜成本 中 —— 已覆盖：预设整体持久化（`copicseal-export-presets`，两页共享，首启种子「默认预设」），重开仍在；旧版「新导入图片自动套用」语义在新交互里不存在（导出按预设显式触发）
- [x] **A6 档位的「应用全部」**｜成本 小 —— 结构性取消：导出预设全局共享，不存在逐张档位，无需复制
