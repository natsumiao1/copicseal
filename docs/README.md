# Copicseal 架构设计书

> **项目**：Copicseal（可图匠）
> **定位**：以图片处理为核心的 Tauri 桌面应用
> **架构**：React 19 + 平台 Contract，Tauri 2 + Rust 承载全部系统能力

---

## 产品定位

Copicseal 是一个以图片处理为核心的 Tauri 桌面应用，聚焦三项能力：

1. 边框水印（Template）
2. 拼图（Collage）
3. 设置中心（Settings）

这不是通用设计软件，也不是素材管理平台，产品只做「快速导入、即时预览、直接导出」的图片生产体验。

以文件夹为文件来源：全局「文件来源」直接浏览本地文件夹内容，点选或拖入时才把图片复制进缓存；不引入项目系统，也不提供归档、项目化管理等素材管理能力；标签与星级只作为筛选维度只读使用（读取图片 XMP 元数据），不提供打标写入。只交付 Tauri 桌面形态，图片处理、本地文件、存储与系统集成均由 Rust 侧提供，不保留浏览器降级路径。

---

## 核心目标

- 围绕单张图或一组图快速生成可发布的结果
- 以真实预览作为主要交互中心，而不是表单或项目树
- 让 Template 与 Collage 成为两个互不干扰的独立功能域
- 通过统一导出管线输出稳定一致的最终图片
- 业务功能只依赖统一的平台能力接口，不绑定具体宿主

---

## 设计原则

| 原则 | 含义 |
|------|------|
| Preview First | Workspace 是真实渲染区，导出结果直接来自该区域 |
| Feature Oriented | Template / Collage / Settings 是唯一一级页面，页面内资产与状态只服务当前功能 |
| No Project System | 不提供项目、画册、工作区切换，不要求先建项目再编辑，导入图片即可开始处理 |
| No Asset Library Page | 不提供素材库页面（归档、项目化管理）；全局只有一份文件来源与一份素材会话，仅底层缓存与文件访问能力复用。标签与星级仅存在于筛选器面板的只读过滤条件中 |
| Desktop Native (Tauri) | 只在 Tauri 桌面端交付；平台 Contract 仍是业务与宿主的唯一边界，只对接 Tauri 宿主，不做 Provider 注册与降级编排 |

## 页面结构

三个一级页面：

```txt
Template   → 边框水印
Collage    → 拼图
Settings   → 设置
```

## 全局布局

两个功能页共用同一套骨架：顶部功能选择条 + 七块可停靠面板（文件夹 / 收藏夹 / 筛选器 / 内容 / 预览 / 调整 / 导出）。

```txt
┌───────────────────────────────────────────────────────────────────────┐
│ TopNav：可图匠 · 边框水印 · 拼图 · 视图 · 设置 ·（窗口控件固定在右端） │
├──────────┬─────────────┬────────────────────────────┬─────────────────┤
│ 文件夹    │             │                            │      调整        │
│ 收藏夹    │    内容      │            预览            │    (面板)        │
│ ──────── │   (面板)      │                            ├─────────────────┤
│ 筛选器    │             │                            │      导出        │
│  (面板)   │             │                            │    (面板)        │
└──────────┴─────────────┴────────────────────────────┴─────────────────┘
        ↑ 七块面板由 dockview 停靠管理：4px 细缝，可换位 / 合并；
          首栏上半默认「文件夹 / 收藏夹」两个 tab、下半为筛选器；
          调整栏上半为调整、下半为导出
```

- 七块面板可拖动 tab 换位（四向分割）、拖到另一面板中心合并为同组 tab；面板间 `4px` 细缝分隔；默认布局里收藏夹与文件夹是第一栏上半的两个 tab、筛选器在其正下方，导出在调整面板正下方
- 每块面板的 tab 条可 ✕ 关闭；「视图」菜单勾选恢复（macOS 系统菜单栏 / Windows 顶栏下拉），布局（位置、尺寸、tab 归组、关闭状态）整份持久化、两个功能页共享
- 设置页使用独立的设置中心布局，不复用业务工作台结构

## 导航与区域规范

### TopNav（顶部功能选择条）

- 位于窗口顶部，高度 `48px`，永久显示、不可折叠
- 图标 + 文字的横向功能切换：边框水印 / 拼图，右端为「视图」菜单（macOS 在系统菜单栏）、设置与窗口控件
- 「视图」菜单勾选显示 / 隐藏七块停靠面板（设置页无工作台时禁用）：macOS 为系统菜单栏的原生「视图」下拉（与应用 / 编辑菜单并列），Windows 为顶栏「视图」下拉；`Cmd/Ctrl+,` 打开设置，macOS 原生菜单「设置…」显示该快捷键
- 无边框窗口的最小化 / 最大化 / 关闭固定在右端；mac 使用系统红绿灯悬浮在左上角
- 整条是窗口拖拽区；功能选择统一在顶部，不再保留侧边图标导航

### Workspace

- 整个系统最重要区域，承担真实渲染与最终导出来源，必须尽可能大
- 运行链路为 `React → DOM → snapDOM → PNG`
- 作为「预览」停靠面板，默认占一行四栏中最宽的一栏（约 45%），最小宽度 `240px`

### Properties

- 以「调整」停靠面板存在：默认占约 20%（栏内上半约 60%），最小宽度 `180px`，可自由拖宽（不设上限）
- 使用 `Accordion` 组织分区

### 导出（Export）

- 以「导出」停靠面板存在：停靠在调整面板正下方（调整栏内约 60 / 40 分高），最小宽度 `200px`
- 面板主体是全局共享的**预设列表**：首行为「新建预设」（虚线按钮行），其下每行第一行为预设名与参数摘要、第二行为常显的操作按钮（导出 / 编辑 / 复制 / 删除，左对齐，最小宽度下完整可见）；行同时是拖放目标——把内容面板的照片拖到行上即按该预设导出
- 按钮生效规则：导出类按钮（导出当前 / 导出全部）需选中照片，编辑 / 复制 / 删除随时可用
- 进行中的任务显示在所属预设行内（已导出 N / M + 取消，两张以上才出现取消）
- 预设两页共用一份并持久化；Template 行内另有「导出全部照片」，拼图页只导出当前画布

### 文件来源（File Source）

- 全局唯一：Template 与 Collage 共用「文件夹 + 收藏夹 + 筛选器 + 内容」四块停靠面板（收藏夹与文件夹默认同组两 tab，筛选器在文件夹栏下方），与预览 / 调整 / 导出同属一套停靠布局
- 面板可拖动换位 / 合并 tab / ✕ 关闭，「视图」菜单恢复，布局跨页共享并持久化
- 拖放 / 粘贴导入与全局素材会话都归它所有，导入进度显示在内容面板顶部
- 目录只通过文件夹树逐级导航选择：唯一顶级入口「计算机」，其下并列用户磁盘（用户主目录）、系统卷（Macintosh HD）与其他磁盘；不提供目录选择对话框，也没有手动刷新入口
- 筛选器面板按星级（1-5 星）、五种颜色标签、长宽比（罗列当前目录实际存在的比例及各自数量）与文件类型过滤内容面板；各条件均为带数量的多选行、条件区可折叠，标签从图片 XMP 元数据只读获取，不提供打标写入
- 文件夹行 hover 浮现星标，点击收藏 / 取消收藏该文件夹；收藏项在收藏夹面板集中展示，只收藏文件夹不收藏文件
- 不提供素材库页面，仅共享底层素材缓存与文件能力
