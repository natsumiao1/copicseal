# Copicseal 架构设计书

> **项目**：Copicseal（可图匠）
> **定位**：以图片处理为核心的 Tauri 桌面应用
> **架构**：React 19 + 平台 Contract，Tauri 2 + Rust 承载全部系统能力

---

## 产品定位

Copicseal 是一个以图片处理为核心的 Tauri 桌面应用，聚焦三项能力：

1. 边框水印（Template）
2. 拼图（Collage）
3. 设置中心（Settings）

这不是通用设计软件，也不是素材管理平台，产品只做「快速导入、即时预览、直接导出」的图片生产体验。

以文件夹为文件来源：全局「文件来源」直接浏览本地文件夹内容，点选或拖入时才把图片复制进缓存；不引入项目系统，也不提供标签、评级、归档等素材管理能力。只交付 Tauri 桌面形态，图片处理、本地文件、存储与系统集成均由 Rust 侧提供，不保留浏览器降级路径。

---

## 核心目标

- 围绕单张图或一组图快速生成可发布的结果
- 以真实预览作为主要交互中心，而不是表单或项目树
- 让 Template 与 Collage 成为两个互不干扰的独立功能域
- 通过统一导出管线输出稳定一致的最终图片
- 业务功能只依赖统一的平台能力接口，不绑定具体宿主

---

## 设计原则

| 原则 | 含义 |
|------|------|
| Preview First | Workspace 是真实渲染区，导出结果直接来自该区域 |
| Feature Oriented | Template / Collage / Settings 是唯一一级页面，页面内资产与状态只服务当前功能 |
| No Project System | 不提供项目、画册、工作区切换，不要求先建项目再编辑，导入图片即可开始处理 |
| No Asset Library Page | 不提供素材库页面（标签、评级、归档、项目化管理）；全局只有一份文件来源与一份素材会话，仅底层缓存与文件访问能力复用 |
| Desktop Native (Tauri) | 只在 Tauri 桌面端交付；平台 Contract 仍是业务与宿主的唯一边界，只对接 Tauri 宿主，不做 Provider 注册与降级编排 |

## 页面结构

三个一级页面：

```txt
Template   → 边框水印
Collage    → 拼图
Settings   → 设置
```

## 全局布局

两个功能页共用同一套骨架：顶部功能选择条 + 五块可停靠面板（文件夹 / 收藏夹 / 内容 / 预览区 / 调整区）。

```txt
┌───────────────────────────────────────────────────────────────────────┐
│ TopNav：可图匠 · 边框水印 · 拼图 · 视图 · 设置 ·（窗口控件固定在右端） │
├──────────┬─────────────┬────────────────────────────┬─────────────────┤
│ 文件夹    │    内容      │                            │                 │
│ 收藏夹    │             │        预览区               │    调整区        │
│  (面板)   │   (面板)     │                            │    (面板)        │
└──────────┴─────────────┴────────────────────────────┴─────────────────┘
        ↑ 五块面板由 dockview 停靠管理：4px 细缝，可换位 / 合并，首栏默认两个 tab
```

- 五块面板可拖动 tab 换位（四向分割）、拖到另一面板中心合并为同组 tab；面板间 `4px` 细缝分隔；默认布局里收藏夹与文件夹是第一栏的两个 tab
- 每块面板的 tab 条可 ✕ 关闭；顶栏「视图」菜单勾选恢复，布局（位置、尺寸、tab 归组、关闭状态）整份持久化、两个功能页共享
- 设置页使用独立的设置中心布局，不复用业务工作台结构

## 导航与区域规范

### TopNav（顶部功能选择条）

- 位于窗口顶部，高度 `48px`，永久显示、不可折叠
- 图标 + 文字的横向功能切换：边框水印 / 拼图，右端为「视图」菜单、设置与窗口控件
- 「视图」下拉菜单勾选显示 / 隐藏五块停靠面板（设置页无工作台时禁用）
- 无边框窗口的最小化 / 最大化 / 关闭固定在右端；mac 使用系统红绿灯悬浮在左上角
- 整条是窗口拖拽区；功能选择统一在顶部，不再保留侧边图标导航

### Workspace

- 整个系统最重要区域，承担真实渲染与最终导出来源，必须尽可能大
- 运行链路为 `React → DOM → snapDOM → PNG`
- 作为「预览区」停靠面板，默认占一行四栏中最宽的一栏（约 45%），最小宽度 `240px`

### Properties

- 以「调整区」停靠面板存在：默认占约 20%，最小宽度 `180px`，可自由拖宽（不设上限）
- 使用 `Accordion` 组织分区

### 文件来源（File Source）

- 全局唯一：Template 与 Collage 共用「文件夹 + 收藏夹 + 内容」三块停靠面板（收藏夹与文件夹默认同组两 tab），与预览区 / 调整区同属一套停靠布局
- 面板可拖动换位 / 合并 tab / ✕ 关闭，「视图」菜单恢复，布局跨页共享并持久化
- 拖放 / 粘贴导入与全局素材会话都归它所有，导入进度显示在内容面板信息行
- 目录只通过文件夹树逐级导航选择（主目录 / 磁盘 / 最近使用），不提供目录选择对话框，也没有手动刷新入口
- 文件夹行 hover 浮现星标，点击收藏 / 取消收藏该文件夹；收藏项在收藏夹面板集中展示，只收藏文件夹不收藏文件
- 不提供素材库页面，仅共享底层素材缓存与文件能力
