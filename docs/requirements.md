# 产品需求规格

> Copicseal 需要实现的产品需求。产品定位、设计原则与全局布局图见 [README.md](./README.md)；
> 各功能域的实现细则见 [features.md](./features.md)。

---

## 1. 产品定义与边界

三个一级页面：`Template` / `Collage` / `Settings`，遵循 README 中的五条设计原则。

Template 与 Collage 的独立边界：

| 共享 | 不共享 |
|------|--------|
| Export Pipeline | 编辑器状态 |
| Asset Infrastructure（含全局文件来源与素材会话） | 页面布局逻辑 |
| EXIF Infrastructure | 属性面板状态、画布状态、导出配置 |

功能域之间的状态互不污染；仅底层缓存、缩略图与文件访问能力复用。

## 2. 核心工作流

### 2.1 Template

```txt
导入图片 → 选择模板 → 调整 Template Props → 预览 → 拖照片到预设导出 / 批量导出
```

- 以单图渲染为核心；模板通过 `propsSchema` 自动生成编辑表单
- 每张图片各持一份模板配置（模板、参数、背景），可一键应用到其余图片；导出参数属于全局导出预设（§5.5、§9）
- 导出结果直接来自 `<TemplateRuntime />`
- 素材来自全局文件来源与素材会话，切换功能页随行

### 2.2 Collage

```txt
文件夹树选目录 → 内容面板选图 → 拖入画布 → 选择布局模式 → 调整布局与选中项属性 → 预览 → 导出
```

- 以多图组合为核心，支持 `Grid Layout` 与 `Free Layout`
- 选中文件夹只枚举路径，缩略图按需生成，图片点选或拖入画布时才复制进缓存
- 记住上次打开的文件夹与停靠布局，重开自动恢复
- 导出结果直接来自 `<CollageCanvas />`

### 2.3 Settings

```txt
进入设置页 → 选择配置分类 → 修改默认行为 → 自动保存
```

配置分类：`General` / `Template` / `Collage` / `Export` / `Cache` / `About`。

- 快捷键 `Cmd+,`（macOS）/ `Ctrl+,`（Windows）随时打开设置页；顶栏 ⚙ 按钮始终保留，macOS 系统菜单栏「设置…」显示该快捷键

## 3. 停靠布局与导航要求

- 七块面板（文件夹 / 收藏夹 / 筛选器 / 内容 / 预览 / 调整 / 导出）由 dockview 统一停靠：可拖动 tab 换位（四向分割）、拖到另一面板中心合并为同组 tab，相邻面板间 `4px` 细缝分隔；默认布局里收藏夹与文件夹是第一栏上半的两个 tab（文件夹为激活 tab），筛选器停靠在文件夹栏正下方，导出停靠在调整面板正下方
- 每块面板的 tab 条显示标题并提供 ✕ 关闭；关闭的面板由「视图」菜单勾选恢复（macOS 为系统菜单栏原生下拉，Windows 为顶栏「视图」下拉），恢复位置为当前激活面板右侧（收藏夹并入文件夹组、筛选器回到文件夹栏下方、导出回到调整面板下方）
- 布局（位置、尺寸、tab 归组、关闭状态）整份持久化，两个功能页共享同一份，重启恢复；设置页（无工作台）时「视图」菜单禁用（macOS 原生菜单项置灰、Windows 下拉禁用）
- 面板最小宽度：文件夹 `140` / 收藏夹 `140` / 筛选器 `140` / 内容 `170` / 预览 `240` / 调整 `180` / 导出 `200`；不提供浮动弹出面板
- 默认布局：顶层一行四栏——文件夹栏 15% / 内容 20% / 预览 45% / 调整栏 20%；文件夹栏内部纵向二分，上半为文件夹 + 收藏夹两个 tab、下半为筛选器（高度约 30%）；调整栏内部纵向二分，上半为调整（约 60%）、下半为导出（约 40%）
- 旧版本保存的布局缺少收藏夹 tab、筛选器面板或导出面板时，首次加载自动补挂一次（收藏夹进文件夹组、筛选器进文件夹栏下方、导出进调整面板下方）；之后是否显示完全由布局本身决定
- 面板改名（预览区 → 预览、调整区 → 调整）对已保存的旧布局同样生效，恢复时统一刷新 tab 标题
- TopNav、Workspace、Properties、文件来源的区域规范见 [README.md](./README.md)「导航与区域规范」

## 4. 全局文件来源（文件夹 + 收藏夹 + 筛选器 + 内容）

全局唯一，Template 与 Collage 共用同一份文件夹状态与素材会话，没有独立工具条行。

### 4.1 文件夹面板

- tab 标题为「文件夹」，✕ 关闭，「视图」菜单恢复
- 唯一顶级入口为「计算机」（虚拟节点，默认展开，不可选中）；其下并列三类节点：
  - **用户磁盘**：用户主目录（macOS `/Users/<名>`、Windows `C:\Users\<名>`），图标为主页
  - **系统卷**：macOS 的系统卷（Finder 所见的「Macintosh HD」，路径 `/`），卷名取实际卷名、取不到时回落「Macintosh HD」；Windows 无此概念，由各盘符代替
  - **其他磁盘**：macOS 外接卷（`/Volumes`，跳过指向 `/` 的符号链接避免与系统卷重复）、Windows 盘符
- 不提供「最近使用」入口；最近打开的文件夹不再作为状态维护
- 点击按需展开子目录，不做递归扫描；选中目录后内容面板加载该目录
- 行尾 hover 浮现星标，点击收藏该文件夹；已收藏的行常显填充星，点击取消收藏
- 只收藏文件夹，不收藏文件；收藏结果集中在同组的「收藏夹」tab 展示
- 不提供目录选择对话框，选目录只能通过文件夹树逐级导航

### 4.2 收藏夹面板

- tab 标题为「收藏夹」；默认与「文件夹」同处第一栏的两个 tab，✕ 关闭，「视图」菜单恢复时优先并入文件夹组
- 按新→旧列出收藏的文件夹（按路径去重）；点击行切换到该目录：内容面板随之加载，文件夹树自动展开到该路径
- 当前打开的文件夹高亮；行尾星标点击取消收藏
- 收藏的是文件夹本身，不提供文件收藏；路径失效时按文件夹面板同样的规则提示，不伪造目录内容
- 尚无收藏时给出空态提示，引导去文件夹面板点击星标

### 4.3 内容面板

- tab 标题为「内容」；信息行放在面板最下方，显示当前文件夹名与图片数，筛选 / 隐藏生效时改为「命中数 / 总数」
- 正在导入时面板顶部显示「导入 N / M」进度与进度条，与底部信息行互不影响
- 缩略图网格展示目录内图片，按文件名排序；大目录需虚拟滚动
- 缩略图占位为正方形：单元格等高等宽，照片在方格内完整显示（留白、不裁切），横竖照片的显示面积相当
- 缩略图按图片自身的显示方向呈现（EXIF 方向在生成时烘焙进像素），竖图不得横放
- 展示集合在「移除隐藏」与筛选器条件之上过滤；条目存在但全部被过滤时提示去筛选器调整，不误报文件夹为空
- 点击选中当前图片，选中态与画布、属性面板联动
- hover 显示「移除」：仅从列表隐藏，不删除本地文件
- 右键条目弹出上下文菜单，含两项：
  - **清空缓存**：清掉该照片的浏览缩略图缓存（派生数据），缩略图立即重新生成；导入副本与预览副本不受影响（由设置页的缓存清理管理）
  - **删除**：先弹确认弹窗（说明将移到系统回收站），确认后把文件移入系统回收站（Windows 回收站 / macOS 废纸篓）并从列表隐藏；失败提示原因、条目保留。已入会话的素材使用缓存副本渲染，不受原文件移走影响
- 未选择文件夹时提示去文件夹面板选择，不提供「打开文件夹」入口
- 不提供手动刷新，目录切换只由文件夹树点选驱动

### 4.4 筛选器面板

- tab 标题为「筛选器」；默认停靠在文件夹栏正下方，✕ 关闭，「视图」菜单恢复时回到文件夹栏下方
- 四个条件区，各维度之间取 AND、维度内取 OR，空维度不限；每项条件都是「复选框 + 名称 + （数量）」的多选行，数量一律是当前目录的总数（不随其它条件变化），标签数据未就绪时星级 / 标签的数量显示 `…`：
  - **星级**：1-5 星五行，多选；数量为该星级的照片数（无评级不计入）
  - **标签**：红 / 黄 / 绿 / 蓝 / 紫五行，多选；数量为该颜色标签的照片数（无标签不计入）
  - **长宽比**：罗列当前目录实际存在的照片比例（把宽高约分为最简整数比，如 4032×3024 → `4:3`），按数量降序；目录里没有的比例不显示，宽高未知的条目不参与统计、且在该维度生效时不命中
  - **文件类型**：从当前目录实际存在的扩展名推导（JPG / PNG / HEIC…），按扩展名排序；目录里没有的类型不显示
- 每个条件区的标题可点击折叠 / 展开，折叠状态持久化
- 星级与颜色标签来自图片元数据中的 XMP（`xmp:Rating` / `xmp:Label`）：只读提取，不提供打标写入；同名 `.xmp` sidecar 优先于文件内嵌 XMP
- 标签数据在当前目录图片枚举就绪后即批量读取（数量显示与星级 / 标签条件都依赖它），读取期间底部显示「正在读取标签…」且标签维度暂不生效（先显示全部，就绪后再收窄），结果按目录缓存、同目录只读一次盘
- 条件持久化（`ratings` / `labels` / `ratios` / `types`）与折叠状态（`collapsedSections`）；标签数据不持久化，按目录重新读取
- 类型与长宽比条件在换目录后自动收敛：目录里没有选中的任何取值时该维度退化为不限
- 底部显示「命中 N / 总数」与「清除筛选」按钮；未选择文件夹时给出空态提示

### 4.5 导入

- 拖拽 / 粘贴：窗口任意位置拖入或粘贴文件，直接进入全局素材会话
- 点击缩略图：懒导入并切为当前预览图片
- 暂不提供「导入图片 / 导入文件夹」工具条按钮；批量加入素材会话的能力后续再补

### 4.6 加载策略

```txt
选中文件夹 → 枚举目录图片路径（不复制原文件）
           → 内容面板按需生成缩略图（源为原文件）
           → 图片拖入画布 / 加入会话时才执行缓存导入
           → 后续预览与导出沿用既有缓存链路
```

- 「移除」记录为会话内的隐藏路径集合，不删除本地文件
- 不依赖项目保存才能继续工作

### 4.7 会话与恢复

- 记住上次打开的文件夹（`folderPath`）与停靠布局，重开自动恢复；全局共享
- 启动时校验路径是否存在，失效则提示去文件夹面板重新选择，不伪造目录内容
- 收藏的文件夹列表持久化，重开后仍显示在收藏夹面板
- 筛选条件持久化，重开后继续生效；标签数据按目录重新读取
- 目录内容变化暂不感知：不做文件监听，也不提供手动刷新（重新枚举需切换到其它目录）
- 文件夹直览为桌面端能力，直接可用，无浏览器降级路径

## 5. Template 页面

路径 `/template`，功能：边框水印、模板渲染、批量导出。

### 5.1 Workspace

渲染 `<TemplateRuntime />`：

- 显示当前模板的真实渲染结果，默认「适应」：画框按「画框比例」（手动覆盖值，否则跟随照片比例）在预览区内等比居中占满，四周留白（letterbox）——预览形状与导出一致，横竖由内容而非面板形状决定，背景不再铺满预览区
- 缩放档位 `Fit` / `50%` / `100%` / `200%`；`100%` 表示照片按原始像素宽度显示（1:1）
- 缩放后画框大于预览区时由滚动条承载，不压缩画面
- 导出结果直接来自当前渲染区域

### 5.2 Properties

采用 `Accordion`，三个核心区块：

- **Template Selector**：单行下拉选择器（Minimal / Film / 白框 / 圆角 / 叠字 / 平铺水印），支持收藏置顶、最近使用排序、键入首字母快速定位
- **Template Props**：表单必须由 `propsSchema` 自动生成，禁止手写模板专用表单；schema 同时定义默认值、类型、控件形态与校验规则
- **背景**：框架级能力，与模板参数体系独立；`无背景 / 纯色背景 / 照片模糊`，默认**照片模糊**（字段兜底与所有模板的默认值统一），纯色模式提供照片主题色盘（前 5 色）；有背景时可调**画框比例**（默认自动跟随照片，可选 `1:1 / 3:2 / 2:3 / 4:3 / 3:4 / 16:9 / 9:16 / 16:10 / 10:16`，竖照片也可选横向让模糊背景横排），与背景其余字段一样逐照片存储并随「应用到其他」复制

### 5.3 配置归属

模板、模板参数与背景都属于**单张照片**，不是全列表共用一份：

- 编辑只作用于当前照片，切换照片时属性面板随之切换到该照片自己的配置
- 未编辑过的照片沿用框架默认配置（默认模板及其默认参数与背景）
- 「模板与参数」可一键应用到其余照片（参数脱离模板没有意义，两者必须一起复制）
- 「背景」单独提供一键应用
- 导出参数不属于照片配置：它是全局共享的导出预设（§5.5、§9）

### 5.4 素材获取

素材统一来自全局文件来源（见 §4），点击缩略图懒导入并切为当前预览图片；导入进度显示在内容面板顶部。

暂不支持：手动排序、素材会话的逐张删除。

### 5.5 导出

导出 UI 集中在停靠于调整面板下方的「导出」面板（见 §3），顶栏只保留标题与描述，不再放导出按钮。面板主体是全局共享的命名预设列表（两页共用一份，持久化见 §9）：

- 「新建预设」是列表**首行**（虚线按钮行，位于全部预设之上），有导出进行中时禁用
- 每个预设一行：第一行为名字 + 参数摘要（格式 / 画质 / 尺寸意图 / 去向与子文件夹），第二行为**常显**的操作按钮（左对齐、与名字同左边距，不依赖 hover，面板最小宽度下五个按钮完整可见）：导出当前照片、导出全部照片、编辑、复制、删除
- 按钮生效规则：「导出当前照片」「导出全部照片」必须**选中照片**才可用；「编辑 / 复制 / 删除」不依赖照片、随时可用（全局进行中时仍禁用）
- **行是拖放目标**：从内容面板拖一张照片到预设行上，即按该预设导出这张照片；尚未入会话的照片先按路径懒导入再导出
- 行内主按钮导出当前显示的照片；「导出全部照片」把素材会话中的全部照片按同一预设逐张导出
- 进行中的任务显示在所属预设行内（该行操作按钮整体替换为进度）：转圈 +「已导出 N / M」+「取消」（任务总数大于 1 才显示取消）；全局同时只跑一个导出，进行中时新建 / 编辑 / 复制 / 删除全部禁用
- 批量导出逐张切换预览并按各自模板渲染；单张失败跳过并在结束后汇总提示，取消在两张照片之间生效并给出已取消提示
- 「新建预设 / 编辑预设」弹窗顶部为名称输入与「存储 / 取消」，下方四个可折叠分区：
  - **存储选项**：存储至（设置的导出目录 / 原始文件位置 / 自定义目录，自定义在选择时打开目录选择器）、存储到子文件夹、管理冲突（创建具有唯一性的文件名 / 覆盖同名文件）
  - **图像格式**：JPEG / PNG；JPEG 可调图像品质 1~100
  - **图像调整尺寸**：**自动（以原图为基准，按原图上限自动计算）**、缩放图像（按百分比，100 即照片原始像素的 1:1）或调整大小至（长边 / 短边 / 宽度 / 高度 + 像素值）；后两种模式可勾选「不放大」（画质优先，不超出照片原始像素）
  - **元数据**：包含原始元数据（EXIF）、删除位置信息（剥离 GPS，仅在保留元数据时可用）
- 本期不提供：分辨率（dpi）、重新采样方法、元数据模板 / 关键字、Content Credentials；对应缺口见 [TODO.md](./TODO.md)

## 6. Collage 页面

路径 `/collage`。Collage 与 Template 的编辑器与布局逻辑完全独立，禁止共享编辑器、布局逻辑、画布 / 模板 / 导出配置状态（边界见 §1）。

### 6.1 Workspace

渲染 `<CollageCanvas />`，支持 `Grid Layout` 与 `Free Layout`；导出结果直接来自当前画布区域。

### 6.2 顶部工具栏

- 布局预设：`2 Grid` / `3 Grid` / `4 Grid` / `6 Grid` / `Auto Layout` / `Free Layout`
- `自适应`：进入自适应布局；切换布局模式会清空自适应树，进入时画布为空；每条分割线带把手，拖动调整两侧占比（双击恢复按照片比例自动推导），整段拖动合并为一步撤销
- `清空画布`：仅自适应模式显示，一键移除画布上的全部照片（只清画布，不删除文件），画布为空时禁用
- `布局库`：弹窗按图片数量分组展示全部布局预设，每项带槽位缩略图；当前布局不属于快捷预设时按钮保持按下态

### 6.3 Properties

`Accordion` 组织，至少包含：

| 区块 | 字段 |
|------|------|
| Layout | 画布比例（6 种预设 + 自定义宽:高输入，画布四角与四边中点的把手拖拽出自由比例——对边锚定：对侧边不动、仅画布向拖拽方向延伸，画面不居中重排，拖到预览区边缘时预览自动跟随（向下/右自动滚动、向上/左钉边延展，拖拽边保持可见，不撞边停住），完成后保持该几何，改比例或视口变化时回归自适应居中；自适应模式默认「跟随内容」，可切固定比例——照片树按自然比例放置（缺省居中、拖拽时贴锚定侧）、余量透出画布背景，照片不裁切）、照片填充（裁切填满 / 完整显示，全布局生效）、间距、边距、背景色、圆角、阴影 |
| Selection | 选中图片后显示：缩放、位置、旋转、圆角；自适应模式：单击照片选中后显示格内取景的缩放（1~3x）与水平 / 垂直位置（按格子尺寸的比例，钳制在不露缝 / 不出格的可达范围内），画布上可直接拖动平移、双击照片重置 |

### 6.4 导出

导出 UI 与 Template 同构：复用同一份预设面板与同一个预设存储（见 §5.5），差异只在触发语义：

- 拖照片到预设行、行内主按钮一律**导出当前画布**——拖来的照片只是触发器，不参与画布内容
- 不提供「导出全部照片」（拼图画布没有逐张批量的语义）；行内主按钮提示为「导出画布」
- 拼图没有单一原图：预设里「原始文件位置」的去向回落到设置的导出目录，且不搬运 EXIF
- 没有照片时整行操作禁用（画布仍需至少一张素材）

## 8. 导出要求

- 导出结果必须来自当前 Workspace 的真实渲染，不依赖隐藏渲染路径或独立编辑器实现
- Template 与 Collage 共用导出基础设施与导出预设，但不共享页面状态
- 导出入口集中在独立的「导出」面板（停靠调整面板下方，见 §3）：预设列表、拖拽导出、行内进度与取消、新建 / 编辑预设弹窗都在该面板内
- 预设是全局共享的命名配置，一份预设描述完整的输出意图（存储、格式、尺寸、元数据），两页共用一份并持久化
- 支持三种触发：拖照片导出单张、当前照片 / 画布、全部照片（仅 Template）；批量导出始终展示进度与可取消状态
- 支持格式与品质、尺寸意图（缩放百分比 / 目标像素）、存储去向与子文件夹、冲突策略、元数据保留与位置信息剥离（管线当前仅开放 `PNG` / `JPG`，WebP 缺口见 [features.md](./features.md) §3.3）
- 文件名默认 `原图名@宽x高`（宽高取尺寸解算实际命中的目标框）；冲突时按预设策略创建唯一文件名（批内去重并检查磁盘）或覆盖
- 导出尺寸由预设的尺寸意图与画布几何解算，不随窗口大小或设备像素比漂移；已知例外与缺口见 [TODO.md](./TODO.md)（拼图缩放相对画布渲染尺寸）
- 不弹保存对话框：目录在预设编辑时一次性选定，子文件夹随导出自动创建

## 9. 存储与状态要求

- 不引入项目系统，不提供素材库页面
- Template 与 Collage 分别维护各自的画布与模板状态；导出参数属于全局导出预设，不随页面或照片走
- 全局文件来源与素材会话由两个功能页共用（应用内唯一一份照片列表）
- 持久化内容仅限：默认配置、模板收藏与最近使用、文件来源状态（当前 / 收藏文件夹）、筛选条件、停靠布局、导出预设、缓存索引
- 业务层通过统一 Platform Contract 访问图片、文件、存储与系统能力，不直接调用宿主 API
